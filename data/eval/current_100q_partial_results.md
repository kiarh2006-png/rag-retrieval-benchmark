# اجرای جزئی ۱۰۰ سؤالی: BM25 fallback

این فایل گزارش یک اجرای آفلاین BM25 روی دیتاست ۱۰۰ سؤالی است. در محیط ساخت بسته، کتابخانه `rank_bm25` نصب نبود و Retriever از fallback داخلی Okapi BM25 با پارامترهای k1=1.5 و b=0.75 استفاده کرد. این نتیجه **جایگزین اجرای نهایی روی سیستم هدف نیست** و نباید به‌عنوان مقایسه سه روش ارائه شود.

| Metric | BM25 fallback |
|---|---:|
| Total queries | 100 |
| Answerable | 90 |
| Unanswerable | 10 |
| Hit@1 | 0.6778 |
| Hit@3 | 0.8889 |
| Hit@5 | 0.9444 |
| Recall@5 | 0.8722 |
| MRR | 0.7826 |
| nDCG@5 | 0.7739 |

خروجی جزئی پرسش‌به‌پرسش در `results/bm25_fallback_smoke_100.json` قرار دارد. ۱۰ سؤال unanswerable از میانگین شش Metric رتبه‌بندی کنار گذاشته شده‌اند و جداگانه شمارش شده‌اند.
